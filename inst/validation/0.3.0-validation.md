## Real-response experiment

Public catalogue XML, exact CLI structure XML and the requested observation
CSV were fetched once on the measurement date. Each installed version replayed
them through the unchanged checksum-verified cache in offline mode. Complete
public comparisons include cache validation and parsing/validation/result
construction, while excluding HTTP latency, request spacing and retries.
Parsed result caches were not introduced.

Public results matched with `identical()`, including factors, classes and
metadata attributes. Component results matched with attributes checked too.
See `PERFORMANCE.md` for timings, method, input sizes, SHA-256 fingerprints and
reproduction instructions. Downloaded OECD responses are not bundled.

## Additional compatibility repair

An existing data.table allocation-state error was reproduced in both 0.2.5
and the initial rewrite with data.table 1.14.10. Assigning Availability through
`attr() <-` in metadata tables invalidated capacity state used by later column
replacement in `describe()`. Two assignments now use `data.table::setattr()`.
The original reproducer and all affected tests then passed, preserving public
values and attributes.

version handling before delivery. Publication requires all six jobs to succeed,

Run full manual/incoming checks and the configured platform jobs before a public

## Reproduce

```sh
R CMD build .
R CMD check --no-manual OECDdata_0.3.0.tar.gz
Rscript --vanilla tools/diagnostics.R .
```

```r
testthat::test_local()
source(system.file("benchmarks", "xml.R", package = "OECDdata"))
```

The no-manual check requires dependencies and vignette build tools. Complete
CRAN checks also need the manual toolchain. The benchmark uses generated offline
inputs by default and validates old/new results before timing.
